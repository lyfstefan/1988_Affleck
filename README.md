# Affleck mean-field calculations

This is the independent Affleck project. It is separate from the author's
[bond-order flux-phase project](https://github.com/lyfstefan/bond-order-flux-phases).

## Files

- `1988_Affleck_code/`: original Python source and its existing usage guide.
- `1988_Affleck_code/results/data/scan_TIMESTAMP.npy`: saved numerical scans.
- `1988_Affleck_code/results/figs/phase_diagram_TIMESTAMP.png` or `.pdf`: corresponding existing figures.
- `file_moves.json`: exact old-to-new filename mapping.

The October 2026 organization changes filenames and locations only. Scientific
source, scan contents and existing figure contents are unchanged; no plots or
phase classifications were regenerated. Scan timestamps pair the data and figures.
The original scripts still write their default paths relative to the working
directory; the saved historical scans have been renamed consistently here.
